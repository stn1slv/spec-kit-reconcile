# BUG-002: Progress bar never appears for small files

**Type**: Defect
**Severity**: Medium
**Status**: Open
**Reported**: 2026-08-11

## Summary

Files under 1 MB upload in a single chunk, and the progress component is never mounted.

## Root Cause Analysis

The component mounts on the first progress event, which a single-chunk upload never emits.

## Proposed Amendment

FR-003 should require the indicator to appear for every upload regardless of size.
