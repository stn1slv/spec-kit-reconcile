# BUG-001: Attachments lost on every deploy

**Type**: Defect
**Severity**: High
**Status**: Fixed
**Reported**: 2026-08-10

## Summary

Every deploy replaced the application container, and attachments written to local disk went with it.

## Root Cause Analysis

Local disk was chosen during prototyping and never revisited. The container filesystem is ephemeral.

## Proposed Amendment

FR-002 should require the object store, and the local-disk wording should be struck.
